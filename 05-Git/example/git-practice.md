
# Git Practical Example

## Objective
To understand and practice basic Git commands.

## Procedure

### Step 1: Initialize Repository
```bash
git init
```

### Step 2: Check Repository Status
```bash
git status
```

### Step 3: Add Files
```bash
git add .
```

### Step 4: Commit Changes
```bash
git commit -m "First commit"
```

### Step 5: View Commit History
```bash
git log --oneline
```

### Step 6: Check File Differences
```bash
git diff
```

## Result
Successfully learned the basic Git commands used for version control and project management.
