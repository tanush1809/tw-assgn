
# 06 - GitHub

## Introduction
GitHub is a cloud-based platform used to store, manage, and share code. It uses Git for version control and allows developers to collaborate on projects.

## Features of GitHub
- Hosts Git repositories online.
- Allows collaboration between developers.
- Provides backup of project files.
- Supports issue tracking and project management.
- Allows code review through pull requests.
- Maintains project history.

## Important GitHub Concepts

### 1. Repository
A repository is a storage location for project files and their version history.

### 2. Remote Repository
A remote repository is a version of a project hosted on a platform like GitHub.

### 3. Clone
Cloning creates a local copy of a remote repository.

```bash
git clone repository-url
```

### 4. Push
Push uploads local commits to GitHub.

```bash
git push origin main
```

### 5. Pull
Pull downloads and integrates changes from GitHub.

```bash
git pull origin main
```

### 6. Fork
Fork creates a personal copy of another user's repository.

### 7. Pull Request
A pull request allows developers to propose changes to a repository.

### 8. Issues
Issues are used to report bugs, suggest features, and discuss tasks.

### 9. README.md
README.md provides information about the project, its purpose, installation, and usage.

## GitHub Workflow

1. Create a GitHub account.
2. Create a new repository.
3. Initialize a local Git repository.
4. Add and commit project files.
5. Connect the local repository to GitHub.
6. Push files to GitHub.
7. Make changes and push updates.

## Advantages of GitHub
- Easy project sharing.
- Team collaboration.
- Online code storage.
- Version control.
- Open-source contribution.

## Conclusion
GitHub is an important platform for developers. It helps manage projects, collaborate with others, and maintain code online.
