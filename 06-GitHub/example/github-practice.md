
# GitHub Practical Example

## Objective
To understand how to create and manage repositories using GitHub.

## Procedure

### Step 1: Create a GitHub Account
Visit https://github.com and create an account.

### Step 2: Create a Repository
1. Log in to GitHub.
2. Click the New Repository option.
3. Enter a repository name.
4. Select Public or Private.
5. Click Create Repository.

### Step 3: Connect Local Repository

```bash
git remote add origin repository-url
```

### Step 4: Check Remote Repository

```bash
git remote -v
```

### Step 5: Push Files to GitHub

```bash
git push -u origin main
```

### Step 6: Download Changes

```bash
git pull origin main
```

### Step 7: Clone Repository

```bash
git clone repository-url
```

## Result
Learned the basic process of creating, managing, and sharing repositories using GitHub.
