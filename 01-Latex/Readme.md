
# LaTeX Documentation

## 1. Introduction

LaTeX is a document preparation system used to create
professional and well-formatted documents.

It is commonly used for research papers, assignments,
technical reports, books and mathematical documents.

## 2. Features of LaTeX

- Professional document formatting.
- Mathematical equations.
- Automatic numbering of sections.
- Tables and images.
- References and citations.
- Bibliography management.

## 3. Basic Structure of a LaTeX Document

A basic LaTeX document contains three main parts:

1. Document class.
2. Document preamble.
3. Document body.

Example:

\documentclass{article}

\begin{document}

Hello World!

\end{document}

## 4. Important LaTeX Commands

| Command | Purpose |
|---|---|
| \documentclass | Defines document type |
| \usepackage | Includes packages |
| \begin{document} | Starts document |
| \end{document} | Ends document |
| \title | Defines document title |
| \author | Defines author |
| \section | Creates a section |
| \subsection | Creates a subsection |
| \textbf | Makes text bold |
| \textit | Makes text italic |

## 5. Mathematical Equations

LaTeX is widely used for mathematical expressions.

Example:

E = mc^2

Quadratic Formula:

x = (-b ± √(b² - 4ac)) / 2a

## 6. Lists in LaTeX

Itemized List:
- First item
- Second item
- Third item

Numbered List:
1. First item
2. Second item
3. Third item

## 7. Advantages of LaTeX

- High-quality document formatting.
- Excellent mathematical support.
- Automatic numbering.
- Suitable for large documents.
- Free and open-source.

## 8. Applications

- Academic assignments.
- Research papers.
- Technical documentation.
- Books and reports.
- Mathematical publications.

## 9. Conclusion

LaTeX is a powerful tool for creating professional
documents, especially when mathematical equations
and structured formatting are required.
